URWA WEBSITE — COMPLETE FRONT-END STARTER
=========================================

This package contains the complete planned page structure:
- Public pages: Home, About, Programmes, Classes, Teachers, Events, Contact, Enroll, Become a Teacher
- Portal pages: portal home, student login/register/dashboard, teacher login/dashboard, admin dashboard
- Shared CSS: css/style.css, css/pages.css, css/dashboard.css
- Shared JavaScript: js/main.js, js/navigation.js, js/firebase-auth.js, js/portal.js
- Existing URWA logo: assets/logo.jpg

HOW TO PREVIEW
1. Extract this ZIP.
2. Open the URWA folder in VS Code.
3. Install/use Live Server if available.
4. Open index.html with Live Server.
5. Navigate through the public pages and Portal links.

IMPORTANT BEFORE PUBLIC LAUNCH
- All forms are front-end demonstrations and do not send/store submissions.
- Portal login/register pages are visual prototypes only. They do not authenticate users.
- Dashboards contain placeholder areas, not live student/teacher/admin records.
- Do not enter real passwords or sensitive personal information.
- Connect an authentication provider and database, implement server-side role permissions,
  secure data rules, and test the complete workflow before enabling real accounts.
- Add approved teacher biographies/photos and verified programme schedules.
- Confirm all membership and growth statistics before publishing them. The About page contains
  figures already present in the supplied project; verify them with URWA before launch.
- Add approved contact details, social links, privacy policy and terms.
- The original homepage is retained and its navigation now links to the new pages.
- No third-party fonts, trackers or external services are required for this starter package.
